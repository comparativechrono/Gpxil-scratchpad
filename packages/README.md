# Packages

New tools for gpxil are written here first, each as a Python package ready to
become a repository of its own and a PyPI package (with its `pyproject.toml`,
tests, README, licence and `.github/workflows`, which run only once it has its
own repository).

When a package is ready it moves to its repository, with its history
(`git subtree split --prefix=packages/NAME`), and is released to PyPI from
there.
